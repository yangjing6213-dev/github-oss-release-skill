# Security Policy

## Supported versions

Security fixes target the latest public version. No older support window or
response-time SLA is promised unless a release notice states otherwise.

## Reporting a vulnerability

Do not disclose an unpatched vulnerability in a public Issue, PR, Discussion,
or log. Use GitHub's private vulnerability reporting for this repository when
it is enabled. If no private channel is available, withhold exploit details
until a maintainer publishes a private contact path.

Include the affected version, impact, minimal reproduction, and suggested
mitigation. Remove tokens, private data, and unrelated system details.

The project will coordinate disclosure based on severity and available
maintainer capacity; no fixed response or remediation time is guaranteed.
