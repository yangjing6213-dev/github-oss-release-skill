# Support

## Supported requests

- Installation and invocation questions.
- Reproducible bugs in the included scripts, references, templates, or tests.
- Documentation corrections and narrowly scoped feature proposals.

Use a GitHub Issue after checking existing Issues. Include the Skill version,
task type, operating system, safe reproduction steps, expected behavior, and
actual behavior. Redact credentials, private paths, private repositories, and
user data.

Security vulnerabilities belong in the private process described in
[SECURITY.md](SECURITY.md), not a public Issue.

The project does not provide emergency response, legal advice, guaranteed
GitHub account recovery, custom repository operation, or a support SLA.
