# Visual asset publication

Process only already-generated, human-approved Logo, Cover, Screenshot, or
Demo assets. Asset generation is outside this skill. For CLI, library, SDK,
API, data, and backend projects, record:

```text
VISUAL_ASSETS_REQUIRED = NO
VISUAL_ASSETS_STATUS = NOT_REQUIRED_FOR_CURRENT_RELEASE
VISUAL_ASSETS_READY = NOT_APPLICABLE
```

When assets are included, verify dimensions, decoding/rendering, truthful
content, watermark, privacy, secrets, third-party logos, provenance, and
redistribution rights. Check README relative paths and ensure reference,
candidate, or source-only images are excluded from the exact manifest. A
missing optional asset is not a blocker; a broken, deceptive, unlicensed, or
secret-bearing asset is.
